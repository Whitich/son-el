# Son El: Kuzgun Malikânesi

index.html dosyasını tarayıcıda açın. Kurulum, internet veya hesap gerekmez.

Gotik blackjack hikâyesi: Kont Vesper, üç masa, iki farklı ek lanet, sınırlı tılsımlar ve iki son. Kurallar oyun içindeki düğmede. Ses kullanıcı açana kadar kapalıdır. Mobil ekranlara uyarlanır. İlerleme yalnız mevcut oturumda tutulur.

K: kart çek, D: kal. Diğer işlemler düğmelerle yapılır. Bölme ve sigorta yoktur; gerçek para kullanılmaz. Kurallardaki blackjack üstünlüğü uygulanır fakat ödeme yerine düşmana hasar vardır.

Test: node test.cjs

Müzik: Kullanıcının sağladığı D Minor Drone.wav. Üst çubuktan müzik ve efektler ayrı yönetilir. Müzik ilk el başladığında çalar, döngüye girer; el sonuçlarında ve yeni hikâyede kesilmez. Ses düzeyi ve açık/kapalı tercihi tarayıcıda saklanır. WAV dosyası yaklaşık 40 MB'dır; ilk yükleme bağlantıya bağlıdır.
